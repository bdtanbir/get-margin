## Specifically check

1. **Highlights, underlines, and strikeouts are selectable and deletable in Acrobat.** This is the
   entire point of the semantic split (`PHASE-2-DESIGN.md` §0). If they render but cannot be
   selected, they were written as page content somewhere and the split has been lost.
2. **Ink is selectable and deletable in Acrobat**, for the same reason.
3. **Text renders in Inter, not a substituted face.** `addSimpleFont` embeds the whole font
   program; a substituted face means the embed did not survive. Compare against
   `test/golden/export-text.png`.
4. **Images and signatures show correct transparency.** A white block behind the signature means
   `removeBackground` did not run — the diagonal stamp in these samples is transparent by
   construction, so any opaque background is a defect.
5. **Links are clickable and go to `https://example.com/`.** `fz_link` draws nothing, so the only
   way to check is to click where the editor drew its dashed affordance.
6. **The rotated and offset samples place everything in the same relative position** as the
   unrotated one. A coordinate bug that only shows on those pages is exactly what
   `export-all-rotated-90.png` and `export-all-offset-cropbox.png` guard, and a viewer disagreeing
   with MuPDF there would be a genuine finding.
